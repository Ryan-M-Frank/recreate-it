# Challenge review record

**Private working record by default.** A filled review may contain spoilers. Publish only a sanitized summary approved by the people whose material it includes.

- Outcome: changes required / ready for playtest / ready for maintainer publication review
- Review limits and missing evidence:

## Checklist

- [ ] Player and GM packet IDs, versions, and mode agree with the manifest.
- [ ] Public input domain, operations, initial state, boundaries, duplicates, ties, and concurrency assumptions are complete.
- [ ] Public examples were independently recalculated from the stated operation semantics.
- [ ] Every acceptance constraint and predetermined stage is disclosed before play.
- [ ] Required bounds are distinguished from optional performance goals.
- [ ] The player file, manifest, title, and public description contain no revealing targets or hints.
- [ ] GM fingerprints have been compared privately with existing challenges.
- [ ] Every evaluation case maps to a public rule; relevant boundaries and updates are covered.
- [ ] Alternative compliant designs are accepted and the hint ladder is opt-in.
- [ ] Correctness, complexity, and novelty statements match the available evidence.
- [ ] Sources, licenses, authorship, prior exposure, and assistance are recorded.
- [ ] Fresh playtest evidence meets the intended release requirements, or is explicitly missing.
- [ ] Local file paths, status, and any weekly timing/intake fields are valid.
- [ ] Publication and defect-handling steps preserve existing pinned attempts.
